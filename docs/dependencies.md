# Dependencies

Every external dependency, behind the interface of ours it sits behind. Written
when the vendor is added.

| Dependency                                | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Interface                                                        |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| WorkOS                                    | Vouches for an email: a six-digit code through its API, behind our own sign-in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `deployment.identity`                                            |
| Resend                                    | Sends sign-in codes and invitation mail. Required for sign-in in production.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `deployment.mail`                                                |
| PostHog                                   | Product analytics, session replay, error tracking, heatmaps, web vitals and surveys: every page seen, click, error and replay, as the person signed in, in the org they are in, tagged local, preview or production. A person is an id and a role, never a name or an email; a replay masks every input and every word. One project on PostHog's US cloud serves all three deployments (`POSTHOG_KEY`, the project token, which is write-only and made for browsers), and its internal-and-test-users filter keeps only production. The browser reaches it through `/ingest` on our origin, and the full build ships in our bundle so nothing is fetched from PostHog's hosts. Missing outside production, nothing is reported and the pill says so; missing in production, the app does not start.                                                                                                                                                                    | `deployment.analytics`, `apps/web/components/analytics.tsx`      |
| Object storage (Tigris, through Fly)      | Profile photos and org logos, in a private bucket: production's own, and a second one with its own keys for previews and laptops, so no key outside production reaches production's data. S3-compatible, so the five `STORAGE_*` values and our one signer are all it takes; billed on the Fly invoice, no egress fees. Tigris has no rule to abort stale multipart uploads (our reap and teardown do that) and answers browser preflights for any origin. A checkout with none of the five values uses a directory.                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `deployment.storage`, `apps/web/lib/s3.ts`                       |
| Composio                                  | Holds a person's accounts in outside apps, several in one app if they like, each with the name they gave it: the OAuth apps, the tokens and the refreshing, behind one REST API, using Composio's own managed OAuth apps. The settings page asks Composio for a person's accounts each time it is shown. Ending a membership or deleting an org deletes its accounts there. One project per environment. The free tier covers the MVP. A checkout with no `COMPOSIO_API_KEY` has three pretend apps; production without one has no connections.                                                                                                                                                                                                                                                                                                                                                                                                                        | `deployment.connections`, `apps/web/lib/composio.ts`             |
| Fly                                       | Runs the computers: a machine with a volume per membership, from the image in `apps/computer`, in one Fly app for production and one for previews and laptops (`maslow-computers`, `maslow-computers-dev`). The image is built on Fly's builders with the owner's own login (`fly deploy --build-only --push --remote-only`, from `apps/computer`) and never on a laptop. The app makes machines through the Machines API with one org-wide token (`FLY_API_TOKEN`, `FLY_COMPUTERS_APP`): in the dev secrets, on Vercel's preview and production, and on the GitHub `preview-db` environment for the hourly reap. Every machine is tagged with its environment, org, member and computer, and outside production with its checkout and lease. The page reads each machine's numbers, CPU, memory, bytes used and open ports, from its door, asked with a ticket the machine's secret signs; nothing on the machine calls us. Billed on the same invoice as the bucket. | `deployment.computers`, `apps/web/lib/fly.ts`, `scripts/fly.mjs` |
| code-server (on the machine)              | VS Code's own web build, from npm, installed into the image at `/opt/maslow` and run inside the person's Linux as `me`: the tree, the editor, the terminal, extensions and its list of open ports. Its data, open files and extensions included, lives in the person's home.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `apps/computer/boot.sh`                                          |
| Claude Code (on the machine)              | Anthropic's coding agent, from npm, installed into the image at `/opt/maslow` and `claude` on the person's path. The person signs in to it with their own Anthropic account. It knows the browser and the brain out of the box, seeded into its settings by the boot.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `apps/computer/seed.mjs`                                         |
| Chromium (via Playwright, on the machine) | The browser tool's own Chromium, headless, fetched from Playwright's store when the image is built, never from the person's disk; with what it needs from Debian. Runs outside the person's Linux as the person, with its profile on the disk.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `apps/computer/boot.sh`                                          |
| Neon                                      | The managed Postgres: production's database, and a branch per pull request off an empty parent. In AWS Ohio (`us-east-2`), where the functions run too; the compute stays on, a quarter to one unit as load asks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `DATABASE_URL`, `scripts/preview-db.mjs`                         |
| Vercel                                    | Hosting and the environment store. Functions run in Cleveland (`cle1`), the database's AWS region, set in `apps/web/vercel.json`. The preview workflow writes a pull request's database URLs there and asks for its one build.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `scripts/preview-db.mjs`, `pnpm env:pull`                        |
| GitHub Actions                            | Runs `pnpm check` on every push and the preview lifecycle on every pull request event, holding the Neon and Vercel credentials on an environment only `main` can use.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `.github/workflows`                                              |
| npm registry                              | Everything a checkout installs, the Postgres binary included.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `pnpm install`                                                   |
| Playwright                                | Drives Chromium for the browser tool, `packages/browser`: the page as an accessibility snapshot with refs, and the clicks, typing and screenshots on it. Its Chromium is fetched by `pnpm exec playwright install chromium` from Microsoft's own servers, the one download that does not come from npm; a checkout without it has no browser tool, and `pnpm check:browser` says so. Apache-2.0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `packages/browser/src/browser.ts`                                |
| gifenc, pngjs                             | Pure JavaScript GIF encoding and PNG decoding, for the browser tool's recordings. MIT.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `packages/browser/src/gif.ts`                                    |
| Agentation                                | Annotating a page for the agent, outside production: click anything, say what is wrong, and the note carries the selector and nearby text an agent can grep for. The toolbar is the npm package, turned on from the pill; the notes reach the agent through its MCP server, `agentation-mcp`, which the developer runs on port 4747 from their own Claude config, and fall back to the clipboard when it is not running. PolyForm Shield licensed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `apps/web/components/annotations.tsx`, the pill                  |
| @modelcontextprotocol/sdk                 | The MCP wire between the brain and an agent: JSON-RPC over one HTTP endpoint, the tool list, and the schemas an agent reads. Every request stands alone and is answered in one JSON body, so it runs on Vercel. The OAuth in front of it is ours: an app describes itself and carries the description as its client id, or names an https address where its description lives, and the token it gets is a session that opens the brain alone.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `apps/web/lib/mcp.ts`, `apps/web/lib/oauth.ts`                   |
| Voyage AI                                 | Turns a record, and a question, into a vector, so recall finds records by meaning (`VOYAGE_API_KEY`; `voyage-4-lite` at 512 dimensions). Vectors live beside the records in Postgres and are compared by brute force, since one person's brain is small. Missing outside production, a stand-in hashes words and the pill says so; missing in production, there is no recall tool.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `deployment.embeddings`, `apps/web/lib/embeddings.ts`            |
