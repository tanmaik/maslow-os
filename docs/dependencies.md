# Dependencies

Every external dependency, behind the interface of ours it sits behind. Written
when the vendor is added.

| Dependency                           | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Interface                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| WorkOS                               | Vouches for an email: a six-digit code through its API, behind our own sign-in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `deployment.identity`                         |
| Resend                               | Sends sign-in codes and invitation mail. Required for sign-in in production.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `deployment.mail`                             |
| Object storage (Tigris, through Fly) | Uploaded images, files on their way to a person's disk, and each disk's daily backups, in a private bucket. S3-compatible, so the five `STORAGE_*` values and our one signer are all it takes; billed on the Fly invoice, no egress fees. Tigris has no rule to abort stale multipart uploads (our sweep, reap and teardown do that) and answers browser preflights for any origin, so the short-lived presigned URL is the guard. A checkout with none of the five values uses a directory.                                                                                                                                                                                                                                                                                                                                                                                             | `deployment.storage`, `apps/web/lib/s3.ts`    |
| Fly                                  | Runs computers: one machine with a volume per membership, in one Fly app of ours, through the Machines API with a token scoped to that app (`FLY_API_TOKEN`, `FLY_COMPUTERS_APP`). The app's hostname fronts every machine: a request naming a machine wakes it, and Fly's proxy suspends it when idle; the image is a whole Debian (node, git, gh, Claude Code, Vercel CLI) copied onto the volume on first boot; the person's home in it is served by the daemon; downloads, the terminal (a shell inside that OS over a WebSocket) and previews of the machine's ports come from the machine itself. Previews get an app of their own with a token scoped to it; their machines and volumes are named for the pull request and destroyed with it, and by the nightly reap. A laptop uses that same app, names its machines `dev-<checkout>-`, and the reap destroys them every night. | `deployment.computers`, `apps/web/lib/fly.ts` |
| Neon                                 | The managed Postgres: production's database, and a branch per pull request off an empty parent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `DATABASE_URL`, `scripts/preview-db.mjs`      |
| Vercel                               | Hosting and the environment store. The preview workflow writes a pull request's database URLs there and asks for its one build.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | `scripts/preview-db.mjs`, `pnpm env:pull`     |
| GitHub Actions                       | Runs `pnpm check` on every push and the preview lifecycle on every pull request event, holding the Neon and Vercel credentials on an environment only `main` can use.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `.github/workflows`                           |
| npm registry                         | Everything a checkout installs, the Postgres binary included.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `pnpm install`                                |
| node-pty, ws (on the machine)        | The daemon's pty and WebSocket server, in the image. node-pty is native code, compiled in the image's build stage and loaded from its prebuilt binary on a laptop; its install script is on the allow-list for that.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `apps/computer`                               |
| @xterm/xterm                         | The terminal in the browser: the one thing on screen beside shadcn, because a terminal emulator is not a component.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `apps/web/components/terminal.tsx`            |
