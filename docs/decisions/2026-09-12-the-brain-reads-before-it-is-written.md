# 2026-09-12 — the brain reads before it is written

Most of what is in a brain the agent put there, so its pages are read far
more often than they are written. Tanishk, sizing it: "I see people needing
to edit records and write things themselves but I think the majority would
be agent-driven." The pages are built for reading at volume, and for
editing that is excellent when it happens and absent when it is not.

## What changed

**The rail says which types matter.** Each carries a bar of how full it is,
read against the fullest type beside it rather than the fullest in the
brain, so a colleague who shared a thousand records does not flatten every
type of the person's own to nothing. The number itself is not shown: how
many is bookkeeping, how much is what a person reads. The types one
colleague shared fold under that person's name, so a brain twenty people
share into is twenty names rather than a hundred types, and a rail of many
types is narrowed by typing part of one.

**The records are rows, not a table.** A title and the first line of what
the record says, whose it is as two letters where it is not the reader's,
and a type's own fields where one type is being read. Gone: the column of
em-dashes, and the type repeated on every row.

**A list is cut two ways.** By type, each gathering its own; or by day,
newest first. The day is when a record happened, falling back to when it
turned up, which is how the door already orders them — so a brain whose
agent sets no dates still reads as a timeline of what arrived.

**A record's body is a document.** What is typed takes its shape as it is
typed, and a slash offers a heading, a list, a quote, a divider or a code
block. There is no mode: the markup never appears.

**The graph stays**, minus the small navigator the graph library drew
inside it, which had no label and read as a rendering fault.

## What did not change

Markdown is still what is stored, in the same column, with one line ending.
An agent reads and writes a body exactly as before; only the person's
surface differs. One read was added — how many records each type holds —
and no table, migration or door shape moved.

## The editor

Tiptap, with `tiptap-markdown`. shadcn has no editor and this is not a
component in shadcn's sense; CodeMirror is already in the app for the Files
editor on the same footing. Nothing else in the interface leaves shadcn.
