# There is no list of verbs

**2026-09-08.** The catalog, the MCP handshake and the link form no longer
name the verbs on a person's links. Nothing computes which verbs are in
use.

A verb was already only the word on a link: not defined, not described,
not a row. The one thing left that treated verbs as a set was a query that
gathered them so the agent could reuse them, and the link form could offer
them. To be true it had to say a verb only while a link carrying it had
both ends still here, which meant following every link in the brain through
its merges and permissions on every page. On production, where an org holds
more than one person's records, that was the slowest thing every brain page
did.

The list did not earn that. An agent describes a link with whatever word
fits; whether the word is new or already on other links is its own
judgment, like every other judgment about what to write, and a person
typing a verb knows what they mean. Filtering the graph by verb and
renaming a verb across links stay, since those act on links a caller
already names.
