# The machine backs its disk up into the bucket

2026-09-04

A volume lives on one host, so once a day each machine archives its whole
disk into Tigris. The bytes go from the machine to the bucket and never
through us: the machine asks the app, as itself, to open a backup, for
somewhere to put each part, and to close it; the app signs and records.
Seven finished backups are kept per person; the eighth goes. One that never
finished within a day goes too. Backups are metered as bucket bytes like
anything else there, and a purge owes them like any other object.

**The sweep drives it.** Each hour, every machine whose last backup is older
than a day is asked to back up and carries on alone; the sweep does not
wait. Being asked wakes the machine. A machine suspended midway carries on
when it wakes, since every part is signed afresh.

**Restore is onto an empty disk only.** The Computer page offers the latest
backup when the root is empty; the machine fetches the archive and unpacks
it. Nothing restores over what is there.

**A full archive each day**, not an incremental one: simple, and honest
about cost. Bucket storage is cheap and the meter shows it. Incremental
backups come when the meter says they are worth it.
