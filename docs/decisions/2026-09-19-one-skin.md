# One skin: shadcn/ui, and AI Elements for the Agent

2026-09-19. BoardUI is out of the product. Every screen is built on
shadcn/ui, and the Agent window on Vercel's AI Elements.

## Why

Tanmai: the app looked like three design systems colliding, ryOS's
desktop, BoardUI's big round parts and shadcn under them, and BoardUI was
the part he liked least. One plain, tight look, as Linear, Things and
Raycast have, was worth more than a bought catalogue. BoardUI Pro's
licence also kept the repository private. Its source is out of the tree
but still in git history, so going public still means leaving that
history behind.

## What

- shadcn's tokens are the source of truth, in one block at the top of
  `apps/web/app/globals.css`: pure grey neutrals, one accent spun from
  the person's pick into `--primary` and `--ring`, a 6px radius, one type
  scale. The rules are in `apps/web/components/ui/README.md`; shadcn's
  preset codes cannot carry an accent that changes at run time, so the
  README and the token block are the preset.
- `apps/web/components/ui` is shadcn's `base-nova` on Base UI, drawing
  Remix icons, changed in a few places only: menus are sheets on a phone,
  floating layers sit over the old desktop's windows, a quiet `plain`
  button, a 400ms tooltip delay, a softer focus ring, square badges.
- The Agent window is AI Elements, taken once as source into
  `apps/web/components/ai-elements` and cut to what the product uses:
  no Streamdown, Shiki, tokenlens or `ai` package; our own Markdown
  draws what the agent says. A step's output now opens under its own row
  instead of in a sheet.
- On a computer the Agent is given shadcn's skill and shadcn's MCP server
  where BoardUI's were, and an app it builds starts from shadcn's CLI.
  Machines get this with the next image.
- The old desktop at `/` keeps its glass and is not restyled; it only had
  its imports moved so it compiles.
