# 2026-09-18 — agents are named, and nothing makes one on its own

The Agent window was a chat app: a New chat button in two places, a fresh
conversation for every question, a rail of them named by the model after
the first exchange. It filled with "Fix the build" and "Plan for Tuesday",
each a process of its own, none of them anyone in particular.

The window is now a rail of agents, modelled on a messenger. Each is a
standing conversation with a name the person gave it when they made it,
a mark of its own colour, the last thing it said under its name and when.
Sales Outbound, Inbox Manager, Chief. The person talks to one of them;
the composer says whose. Making one is a deliberate act with a name
typed first, so nobody makes one willy-nilly and every one in the rail
is someone the person recognises. The window opens on the last agent
spoken to, never on an empty one, on the desk as on the phone.

Underneath nothing moved: an agent is the same conversation the door
kept before, its own Claude Code, closed after three quiet minutes and
opened again whole. What the door keeps beside the session id is the
name and the last line said. The model no longer names anything; that
code is gone.

Not here yet: agents speaking to each other, as the messenger shows, and
a routine an agent runs on a schedule. Each is its own decision.
